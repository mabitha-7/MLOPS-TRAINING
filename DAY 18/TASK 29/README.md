AI Job Alert Bot 🚀
An automated job alert system built using n8n, Telegram Bot API, and RemoteOK API to help students and freshers receive daily AI/ML-related job opportunities directly on Telegram.

📌 Project Overview
Finding relevant job opportunities every day can be time-consuming for students and freshers. This project automates the process by collecting job listings from RemoteOK, filtering relevant AI/ML and data-related roles, and sending them directly to a Telegram bot.

The system runs automatically on a schedule and delivers curated job opportunities without requiring manual searching.
