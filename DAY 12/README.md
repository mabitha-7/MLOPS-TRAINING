## 📖 Project Overview

Worker Safety AI System is an AI-powered workplace safety monitoring application designed to identify potential hazards and assess risk levels from incident descriptions, images, audio, and video inputs.

The system combines Computer Vision and Machine Learning techniques to improve workplace safety by detecting Personal Protective Equipment (PPE) compliance and identifying hazardous situations in real time.

---

## ✨ Features

✅ PPE Detection using YOLOv8
✅ Risk Prediction based on Incident Descriptions
✅ Video Hazard Analysis
✅ Image-based Safety Inspection
✅ Audio Input Support
✅ Real-time Safety Assessment
✅ Cloud Deployment on AWS EC2
✅ Dockerized Application Deployment
✅ Responsive React Frontend

```text

                ↓

                ↓

                ↓

                ↓
```

## 🚀 Installation

### 📥 Clone Repository

```bash
git clone <repository-url>
cd worker-safety-project
```

### ⚙️ Backend Setup

```bash
pip install -r requirements.txt
python app.py
```

### 🎨 Frontend Setup

```bash
cd client
npm install
npm start
```

### 🐳 Docker Deployment

```bash
docker build -t worker-safety-final:v1 .
docker run -p 5000:5000 worker-safety-final:v1
```
